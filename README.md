## FAQ

**What source port should I use?**  
GZDoom for modern features and mods. Crispy DOOM or DSDA for vanilla-accurate gameplay.

**Do I need the original DOOM IWAD?**  
Yes — you need DOOM.WAD or DOOM2.WAD (buy on Steam for $5 or use the free Freedoom IWAD).
